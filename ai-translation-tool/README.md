# 🌐 AI-Powered Language Translation Tool

A premium modern translation app built with **Python + Streamlit** featuring:
- Glassmorphism UI
- Gradient animated background
- Dark mode inspired design
- Real-time translation
- Text-to-speech
- Translation history

## 🚀 Setup Guide

```bash
# Clone repo
git clone https://github.com/yourusername/ai-translation-tool.git
cd ai-translation-tool

# Install dependencies
pip install -r requirements.txt

# Run app
